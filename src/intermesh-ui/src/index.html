About transfers and recovery

Amounts must be positive and no greater than €9,999,999,999,999.99, with up to two decimal places.

Status checks are read-only. Resending a saved request uses the same UUID and unchanged values; it does not restart an admitted workflow. Transfers are never automatically retried.

Requests are saved in this tab for the signed-in user, including after logout. Sign in as the same user to recover them. Browser storage is specific to this frontend origin and does not move between network1 and network2. Closing the tab can remove saved requests.
